# TaskMate 课程资料第二大脑 · 可交互原型

第二次团队作业（原型设计 + 概要设计）的原型部分。前台学生端 8 页 + 后台管理端 5 页，共 13 个页面，全部可点击。

## 入口

- 墨刀原型（推荐，从总览页进）：https://pb-cbo44xzbl2bmc5rnf2twdsolqgx4rlpfgl5weua.ai.modao.ink/overview.html
- 墨刀原型（从登录页开始体验完整流程）：https://pb-cbo44xzbl2bmc5rnf2twdsolqgx4rlpfgl5weua.ai.modao.ink/login.html
- 备用在线预览：https://taskmate-prototype.app.workbuddy.host/?sharecode=POKDQYCAOS
- 本地：直接双击 `index.html`，纯前端，不用装任何环境

## 页面清单

- 前台（学生端）：P1 登录/注册、P2 工作台、P3 上传资料、P4 解析预览、P5 溯源问答、P6 复习卡片、P7 DDL 待办、P8 历史问答
- 后台（管理端）：P9 管理首页、P10 用户管理、P11 资料管理、P12 问答监控、P13 系统配置
- 顶部导航可以一键切换前台 / 后台

## 重点功能

- 问答的每条回答下面都标了"来源：课件第 X 页"，问和资料无关的问题会直接回复"资料中未找到相关内容"。这是第一次作业问卷里用户提得最多的要求，所以把它放在最显眼的位置；
- 资料里识别出"几月几号截止"这类句子会高亮，确认后可以同步回上一版 TaskMate 待办，两个产品接上了；
- 不勾隐私声明的话，登录和上传按钮都是灰的，对应我们自己定的验收标准 A7。
